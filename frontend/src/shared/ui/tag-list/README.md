# shared/ui/tag-list — TagList

## Будет ли переиспользоваться?

Да, с самого начала — три существующих места уже рендерили один и тот же
`Work.stack`, каждое по-своему: полный список `<Tag>`'ов на `/work/:slug`,
`·`-разделённый обычный текст (первые 3 технологии) на карточке лендинга
"Selected Work", и такой же `·`-текст (первые 2) в ledger `/work`. Один
компонент с одним пропом (`maxVisible`), а не три копии одной и той же
идеи усечения списка.

## 2026-08-11 — Первая версия, часть унификации Work/Post UI

**Что нужно было сделать.** Пользователь явно попросил унифицировать все
появления одинаковых данных на сайте ("не хочу чтобы на одной странице
было так, а на другой по-другому") — чипы технологий были самым явным
случаем: одна и та же информация показывалась то как реальные `<Tag>`,
то как голый текст через точку.

**Как сделано.** `TagList` оборачивает уже существующий `Tag` — не
переизобретает вид чипа, только решает, СКОЛЬКО их показать.
`maxVisible` не задан → рендерятся все (детальная страница). `maxVisible`
задан → рендерятся первые N, а для остатка — один `<Tag variant="outline">
+K</Tag>`.

**Понятность для другого разработчика.** "+K" не кликабелен — сознательное
решение, не недосмотр (см. комментарий в самом компоненте): везде, где
`TagList` используется в свёрнутом виде, рядом или вокруг уже есть ссылка
на страницу элемента с полным списком, а `<button>` внутри `<Link>`,
которым обёрнута строка `/work`-ledger — невалидный HTML (интерактивный
элемент внутри интерактивного). Добавление `title` на "+K" — маленький
бесплатный бонус (подсказка при наведении, что именно скрыто), не часть
основного требования.

**Нагрузка.** Ноль — чистый рендер без стейта, без эффектов.

**Расширяемость/заменяемость.** `variant`/`size` пропущены насквозь в
`Tag` — новый вариант оформления `Tag` автоматически доступен и здесь,
без изменений в `TagList` самом.

**Миграция/отказоустойчивость.** Не применимо — чистый презентационный
компонент, не читает и не пишет данные.

**SOLID.** Single Responsibility: `TagList` не знает, что стоит за
строками (технология, категория, что угодно ещё) — это дело вызывающей
стороны; он умеет ровно одно — показать список текстовых тегов с опциональным
усечением.
