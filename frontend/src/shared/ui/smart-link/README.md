# shared/ui/smart-link — бейдж, строка и карточка ссылки

## Будет ли переиспользоваться?

Да: публичные страницы поста и кейса (через `ContentBlocks` и `Markdown`) и
админский редактор (`block-editor/blocks/LinkCardBlock.tsx` показывает
ровно этот же `SmartLinkBlock` как превью).

## 2026-10-28 — Три вида smart link

**Что нужно сделать.** Показать ссылку как в Confluence/Jira: бейдж в
тексте, компактная строка или полная карточка с картинкой (макеты «Smart
link cards», решение — документ «Smart links: техническое решение»).

**Как сделано.**

| Файл | Что делает |
| --- | --- |
| `SmartLinkBadge.tsx` | inline-бейдж для `[label](url "smart")`: иконка, заголовок, ↗ или «project»/«post» для своего контента |
| `LinkRow.tsx` | компактная строка: иконка, заголовок, домен, маленькая картинка |
| `LinkCard.tsx` | полная карточка: картинка 1200×630 (через `CoverImage` с LQIP) или панель с иконкой, заголовок, описание, домен |
| `SmartLinkBlock.tsx` | блок `linkCard`: выбирает строку или карточку; без превью — обычная ссылка с доменом |
| `SiteIcon.tsx` | favicon или буква домена; свой Work/Post — плитка в его identity hue |
| `SmartLinkAnchor.tsx` | единственный `<a>`: чужие страницы в новой вкладке с `noopener noreferrer`, свои — `next/link` |
| `LinkPreviewContext.tsx` | превью документа (`getLinkPreviewsForBlocks` на сервере) доступны любому `Markdown` внутри него |

- Компоненты ничего не фетчат. Данные приходят готовыми: страница один раз
  читает снимки из БД и кладёт их в `LinkPreviewProvider`
  (`ContentBlocks`'s `linkPreviews`).
- Всё, что пришло с чужого сайта (заголовок, описание), — обычный React
  текст, никогда не HTML. Картинки и иконки — уже перекодированные файлы с
  нашего `/media`, не удалённые `<img>`.
- Любое состояние снимка (нет, упал, без заголовка) рендерится как обычная
  ссылка, а не пустое место и не ошибка. Ошибку фетча видит только автор в
  редакторе.
- Тинт своего контента — `accentTintForHue` (`shared/lib/hue-accent.ts`),
  тот же hue, что у обложки кейса.

**Понятность / нагрузка / расширяемость / миграция / SOLID.** Один
компонент на один вид, общий `SmartLinkAnchor` и `SiteIcon` вместо копий.
На публичной странице ноль сетевых запросов и ноль JS-логики кроме
рендера. Новый вид (например, карточка GitHub из бэклога) — новый
компонент рядом и ветка в `SmartLinkBlock`, данные (`LinkPreviewView`) те
же. Тесты: `SmartLink.test.tsx` (бейдж с превью и без, маркер `"smart"` не
попадает в DOM, title override, своя ссылка в той же вкладке).
