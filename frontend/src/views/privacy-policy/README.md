# views/privacy-policy — PrivacyPolicyPage

## 2026-11-17 — публичная страница политики конфиденциальности приложения IP Cameras Hub

**Что нужно сделать.** Google Play требует публичный адрес политики
конфиденциальности (активный, не PDF, не редактируемый). Приложение — Android,
у него нет своего сайта, поэтому политика публикуется здесь:
`/privacy/ip-cameras-hub`. Исходный текст и доказательства каждого утверждения
лежат в репозитории приложения (`docs/release/privacy-policy.md` и
`docs/verification/privacy-policy-evidence-2026-11-17.md`).

**Как сделано.** Текст — типизированные данные (`PolicyDocument`:
заголовок, дата, вступление, разделы из абзацев, списков и таблиц), страница
только рисует их. Строки — inline-Markdown через существующий `Markdown`
(жирный, код, ссылки; сырой HTML он не исполняет). Таблицы — семантический
`<table>` с `th scope="col"`, на узком экране прокручиваются вбок.
Адрес для вопросов — одна константа `PRIVACY_CONTACT_EMAIL`; смена адреса —
одна строка.

**Что пробовали и отвергли.** Взять `Markdown` целиком для документа: он
сознательно убирает обёртку `<p>` (рассчитан на один блок текста) и не
поддерживает таблицы (нет GFM). Добавлять GFM ради одной страницы значило бы
менять общий компонент, поэтому таблицы и блоки рисуются отдельно, а `Markdown`
остаётся для строк внутри них.

**Почему страница `force-dynamic`.** Текст — константа репозитория и в базе не
хранится: правка через админку невозможна, это и есть защита политики. Но
`(site)/layout.tsx` читает конфиг сайта из БД для меню и подвала; статический
пререндер заморозил бы их при сборке (тот же довод, что в `journal/page.tsx`).

**Понятность для другого разработчика.** Три маленьких компонента по одной
обязанности: страница, блок (абзац/список/таблица), таблица. Текст отдельно от
вёрстки.

**Нагрузка.** Рендер без запросов к БД самой страницы; единственное чтение —
конфиг для меню, с откатом `getSiteConfigSafe()`.

**Расширяемость/заменяемость.** Вторая политика (другое приложение) — новый
`PolicyDocument` и новый маршрут, без правок компонентов. Русская версия —
второй документ и `alternatesFor(path, locale, ["en", "ru"])`.

**Миграция/отказоустойчивость.** При недоступной БД меню и подвал берутся из
запасных значений, сама политика остаётся целой. Адрес `/privacy/ip-cameras-hub`
нельзя менять: Google Play хранит его в карточке приложения.

**SOLID.** Single Responsibility: данные, выбор блока и вёрстка таблицы в разных
файлах; Open/Closed: новый вид блока — новая ветка в `PolicyBlock` и в
`PolicyBlockView`, остальное не меняется.

**Проверено.** Модульные тесты (`PrivacyPolicyPage.test.tsx`): структура страницы,
таблицы, ссылки на почту, отсутствие старого названия приложения, только https.
Страница не смотрелась в браузере и не проходила визуальные/a11y-тесты
Playwright (требуют локальной БД): нужен просмотр в реальном браузере, особенно
таблиц на узком экране.
