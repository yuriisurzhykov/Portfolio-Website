# Content properties

## 2026-10-29 Separate metadata from writing

Journal metadata and Work card/case-study properties are controlled field sections. They share controls and option selection but keep domain-specific payload shapes explicit. Views own values, persistence and publication feedback. The URL field is a slot, avoiding a cross-feature dependency.

Work tabs change only the visible metadata. A populated case-study package is removed only after explicit confirmation. Card-only projects remain supported. Images remain URL-backed; no upload service or new content format is introduced.
