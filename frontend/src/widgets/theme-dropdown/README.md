# ThemeDropdown

## Назначение

Компактный переключатель темы для навигации. В закрытом состоянии
показывает только иконку выбранного режима. В открытом состоянии
показывает иконку и локализованное название каждого режима.

## Устройство

`shared/ui/icon-dropdown` отвечает за раскрытие, размещение меню,
управление с клавиатуры и закрытие по клику вне компонента.

`widgets/theme-dropdown` связывает этот общий компонент с существующим
`ThemeProvider`. Состояние темы и его сохранение остаются в
`shared/theme`; виджет не использует собственный `localStorage`.

Меню выводится через portal в `document.body`. Это сохраняет его
расположение при использовании внутри шапки с `backdrop-blur`.

## Настройка

`className` изменяет оформление кнопки. `options` ограничивает список
режимов. Текущий выбранный режим всегда включается в меню, даже если
он отсутствует в `options`, чтобы значение кнопки оставалось
представленным в списке.

## Доступность

Кнопка имеет текстовое `aria-label`, `aria-haspopup` и `aria-expanded`.
Пункты меню используют `menuitemradio` и `aria-checked`. Поддерживаются
Escape, стрелки, Home и End. После выбора фокус возвращается на кнопку.

## Миграция и зависимости

Миграция данных не требуется. Новых пакетов нет. Используются
существующие `shared/theme`, `shared/i18n` и `lucide-react`.
